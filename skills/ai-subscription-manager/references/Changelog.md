## [1.2.1] - 2026-08-28

### 新增

- **仪表盘「API 余额资产」板块**：余额卡片、消耗进度条、寿命徽标与低余额预警条；总支出口径升级为「订阅 + API 余额」双口径。
- **余额在线同步**：`balance_analyzer.py sync` 可拉取 DeepSeek / Moonshot 官方余额，与本地记录比对并保留差额留痕。

---

## [1.2.0] - 2026-08-28

### 新增

- **用量分析**：新增 `usage` 子命令，按周期看各订阅与 API 的实际消耗。
- **场景化重叠检测**：按使用场景（写代码 / 写作 / 生图 / 会议纪要等）判断重复订阅，比按功能标签更贴近实际使用。
- **定价保鲜**：`price_updater.py` 支持在厂商调价后更新本地价库。
- **token 级任务成本预测**：`task_estimator.py` + `token_prices.json`，按任务模板折算「跑一批要多少钱」，含峰谷分时计价与错峰建议。
- **API 余额资产分析**：`balance_analyzer.py` + `balances.json`，按消耗速率折算预计耗尽日期、低余额预警，并给出模型路由建议。
- **仪表盘 30 秒指引**与**到期自动提醒**：打开即知下一步该做什么，到期前按配置自动提示。

### 优化

- 全脚本统一读取 `rates.json` 汇率口径，跨币种金额不再各自换算。

---

## [1.1.0] - 2026-08-26

### 新增

- **产品库扩至 50 款**（首发为 36 款），覆盖主流对话 / 编程 / 生图 / 音视频 / 办公类 AI 产品。

### 修复

- **自动续费解析**：修正 `auto_renew` 字段解析，避免续费状态显示与实际不符。
- **仪表盘空状态**：无订阅记录时给出引导文案，不再显示空白页。

### 调整

- 数据文件读写权限收紧，导出与备份路径不再暴露本机目录结构。

---

## [1.0.0] - 2026-08-21
